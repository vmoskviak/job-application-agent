# job-application-agent

An open-source, self-hosted job-application agent: Claude Code running headless plus deterministic Python for scraping, scoring, Playwright form-filling and CV rendering. Each person runs their own copy under their own accounts; there is no hosted service.

- Source code and documentation: https://github.com/vmoskviak/job-application-agent
- [Privacy Policy](privacy.html) for the Gmail integration
