# Crontab for the server (root in LXC), TZ=Europe/Berlin.
# Install: crontab /opt/jobsearch-autopilot/scripts/server/crontab.txt
#
# 20:30: evening discover (digest, no applications) for all active clients
# 03:00: morning apply (applications + mail + report) for all active clients
#
# Clients run one after another under a single lock; one run times out after 3h.
# With two active clients the morning window can stretch to about 09:00. If that
# collides with the daily subscription limit, move the start earlier.
#
# Trial mode (shadow): uncomment the APPLY_MODE line, comment out the live one.

SHELL=/bin/bash
PATH=/usr/local/bin:/usr/bin:/bin:/usr/local/sbin:/usr/sbin

30 20 * * * /opt/jobsearch-autopilot/scripts/server/run_all.sh evening
0 3 * * *   /opt/jobsearch-autopilot/scripts/server/run_all.sh morning
# Trial (shadow, dry-run): instead of the live morning line:
# 0 3 * * *   APPLY_MODE=dry-run APPLY_GUARD_LIMIT=10 /opt/jobsearch-autopilot/scripts/server/run_all.sh morning
